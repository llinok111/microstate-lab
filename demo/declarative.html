Declarative usage

No mount…() calls anywhere on this page. Markup declares the interaction with data-ms attributes and the runtime does the rest. View source — the only script tag is the runtime itself.

Press — attributes only

<button data-ms="press" data-ms-duration="180" data-ms-easing="ease-out">Continue</button>

Consumer class survives adoption

<button class="host-btn" data-ms="press">…</button> → the class moves onto the mounted button

Async button — real promise, not a timer

<button data-ms="async-button" data-ms-action="save">Save</button>

Disclosure

<div data-ms="disclosure" data-ms-title="Delivery options"></div>

Switch with persistence

<button data-ms="switch" data-ms-persist="auto-save">Auto-save drafts</button>

Reload the page — the state is remembered.

Drag-sort from a plain list

<ul data-ms="drag-sort"><li>…</li></ul> → the list items are the data
